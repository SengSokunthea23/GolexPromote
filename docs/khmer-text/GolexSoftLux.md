### Editing notes

- Change only the text between the quotes `'…'` (or between `>…<` for text inside a tag).
- A `|` inside the code splits a headline into words that animate one by one. It is shown here as a space. Keep `|` between words, and never inside a word (it would break subscripts such as `្ញ`).
- After editing, re-render with `npm run render:soft`.
